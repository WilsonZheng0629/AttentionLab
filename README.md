# AttentionLab

## Overview

AttentionLab is a creator analytics dashboard that analyzes short-form content performance across TikTok, Instagram Reels, and YouTube Shorts.

## Business Problem

Creators often struggle to identify which content strategies generate the highest engagement and production ROI.
