# AttentionLab

## Creator Intelligence Dashboard

### Project Overview

AttentionLab is a creator analytics platform designed to help content creators identify which content strategies generate the strongest performance across short-form video platforms.

The platform analyzes content performance across TikTok, Instagram Reels, and YouTube Shorts and provides recommendations based on engagement, reach, posting patterns, and production ROI.

---

## Business Problem

Content creators often make decisions based on intuition rather than data.

Questions such as:

* What topics perform best?
* Which hooks generate the strongest engagement?
* What video lengths should be prioritized?
* When should content be posted?
* How much production effort is justified?

can be difficult to answer without structured analytics.

The goal of AttentionLab was to transform content performance data into actionable recommendations.

## Key Insights

### Insight #1

AI-focused content generated the highest average reach.

### Insight #2

Tutorial-style videos produced stronger engagement rates.

### Insight #3

Videos between 15–30 seconds consistently outperformed longer content.

### Insight #4

Weekend publishing windows generated stronger average performance.

### Insight #5

High-performing content frequently required less editing effort than expected.
